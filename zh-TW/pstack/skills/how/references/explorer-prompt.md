# Explorer Prompt Template（探索者提示詞模板）

用這個模板建構每個探索者子代理的提示詞。填入佔位符。

---

其他探索者正在平行調查同一個子系統的不同區塊。不要試圖涵蓋一切。專注在被分配給你的角度，深入挖掘。

## 輸出

### Components Found（找到的元件）
關鍵的型別、服務、類別和抽象。每一個寫出：名稱、檔案路徑，以及一句話描述它做什麼。

### Flow（流程）
一步一步的執行流程。每一步寫出：執行哪個函式/方法、它在哪個檔案、它做什麼、它接著呼叫什麼。包括在步驟之間流動的資料。

### Files Read（讀過的檔案）
你在探索中讀過的每個檔案，讓解說者可以引用。

### Boundaries（邊界）
這個子系統與程式碼庫其他部分連接的地方。輸入與輸出。

### Non-Obvious Things（不明顯的事）
任何令人意外、有歷史原因或容易弄錯的東西。看起來應該這樣運作、實際上卻那樣運作的東西。

### Open Questions（未解的問題）
任何你無法完整追蹤或理解的東西。誠實面對缺口。
