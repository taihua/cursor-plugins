# How（怎麼運作）

探索程式碼庫來回答「X 怎麼運作？」的問題。

如果範圍有歧義，說明你的解讀並開始探索。使用者可以再調整方向。

## 1. 解釋

派一個 Task 子代理，使用 `subagent_type: generalPurpose` 和 `readonly: true`，一次完成探索和解釋。給它使用者的問題和這份說明：

> 你要為一位資深工程師撰寫架構解釋。探索程式碼庫，寫出一份解釋，讓一位不熟悉這個領域的資深工程師讀完之後，能帶走一個扎實的心智模型。他們應該對架構了解到足以有信心地開始在其中工作。你對程式碼庫只有唯讀權限。

## 2. 呈現

呈現子代理的輸出。為了清楚或補上對話中的脈絡而做輕微的修改沒問題，但不要大幅改寫。
