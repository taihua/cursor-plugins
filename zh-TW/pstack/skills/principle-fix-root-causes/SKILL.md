# Fix Root Causes（修正根本原因）

修正故障本身，而不是它浮現的地方。根本原因是系統第一次做了它不該做的事，或沒有處理它應該處理的狀態的地方。

- 先重現。一直問「為什麼」，直到答案是程式碼中的一個錯誤決定。卡住時，就埋點量測，讀實際的狀態。
- 問：觸發症狀的那個狀態是合理的嗎？如果是，就在程式碼壞掉的地方處理它。如果它根本不應該存在，在那裡加檢查只是在藏 bug，所以要找出是什麼產生了它。防護、重試、吞掉錯誤、夾限數值和丟棄狀態，是藏 bug 的常見手法。
- 修正模式，而不只是這一個實例。找出每個有同樣故障的地方。
- 如果決定性的事實要挖得很深才找得到，就提議一個便宜、隨時開著、能讓人第一眼就看到它的訊號。
