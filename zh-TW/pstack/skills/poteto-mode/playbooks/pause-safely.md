### Pause safely（安全暫停）

**乾淨地停下由你負責。留下一個冷啟動的 agent 能接續的檢查點。** 只在明確要求時進行。遇到「keep going」、「going to bed, keep going」或「don't stop」時，不要暫停。

1. 停在安全的邊界。完成目前的原子步驟，或退出它。不要開始任何新東西，並取消所有巢狀的子代理。
2. 不要為了暫停而做任何不可逆的動作。除非你已經有一個發出去了，否則不開 PR、不推送。
3. 讓工作持久保存。把未提交的修改在目前分支上提交成一個清楚的 `wip:` commit，這樣什麼都不會遺失。如果程式碼樹是壞的，在 commit 內文用一行說明。
4. 把接續說明寫在上下文之外。記錄意圖、你正在做什麼、進度與已驗證的部分、目前狀態、下一步、關鍵檔案和陷阱。如果是因為上下文壓縮而觸發，就寫到像 `/tmp/<slug>-resume.md` 這樣的檔案。如果已有 show-me-your-work 紀錄，就指向它，不要重複。

**回覆：** 你在迴圈中的位置、哪些已經在磁碟上、哪些還只在你腦中（給路徑，不要傾倒 diff）、你做的 commit 以及程式碼樹是否乾淨、接續時的第一個動作。這是暫停，不是最終報告。
