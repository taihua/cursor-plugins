# Slack Conversations（Slack 對話）

## 如何搜尋

Slack MCP 工具各不相同。先確認有哪個 Slack MCP 可用，並檢查它的工具 schema。它可能需要 `mcp_auth`。如果認證失敗，停下並回報缺口。

1. **限定作者的搜尋。** PR 作者在 PR 合併日期附近的訊息。這能大幅限縮範圍，而且常常挖到寶。
3. **PR 網址搜尋。** Slack 常常在審查或討論 PR 時連結它。搜尋 PR 網址（或只搜 `/pull/<number>`）。
4. **錯誤字串搜尋。** 如果程式碼處理某個特定錯誤，搜尋那個錯誤字串。事件討論串常常會浮現。

> 譯註：原文編號就是從 1 跳到 3。

## 常見陷阱

- **頻道考古的限制。** 很舊的訊息可能因為保留政策而消失。如果某個日期之前什麼都找不到，記下這個保留期限斷崖。
- **沒有被搜尋的私訊。** 很多決定發生在無法搜尋的私訊中。你會漏掉它們，這是已知的限制。
- **把推測性的玩笑當成「決定」。** Slack 很隨性。「哈就做那個吧」不是決定，即使它出現在 commit 之前。找經過考慮的討論。
- **單則訊息的脈絡崩塌。** 沒有討論串，單則訊息讀起來常常和在脈絡中不同。一定要取得整個討論串。
- **認證失敗。** 如果 MCP 沒有通過認證，停下。不要捏造發現。回報 Slack 無法搜尋。
