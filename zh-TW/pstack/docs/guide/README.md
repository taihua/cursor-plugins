# pstack 新手指南（繁體中文版）

> 本指南翻譯自 [`pstack/docs/guide/`](./README.md)。範例提示詞已改寫成中文，你可以直接複製使用——agent 看得懂中文。斜線指令（如 `/poteto-mode`）請照打英文。看不懂的詞請查 [術語表](../../README.md#術語表)。

當你不再對 agent 事事插手時，pstack 的效果最好。你只要描述「想要什麼」以及「怎樣算完成」。`/poteto-mode` 會挑選劇本，在步驟需要時執行其他技能，並把證據拿給你看。這份指南用實際的提示詞教你養成這個習慣。

你會學到：

1. [設定 pstack](./01-setup.md)：安裝 plugin，挑選模型。
2. [透過 `/poteto-mode` 分派工作](./02-poteto-mode.md)：給它一個目標，看它挑劇本。
3. [理解程式碼](./03-understand.md)：先做唯讀調查，再用 `/how`、`/why`、`/teach`、`/recall`，改任何東西之前先搞懂。
4. [設計變更](./04-design.md)：在程式碼定型前，用 `/architect`、`/arena`、`/swarm`、`/interrogate`、原型和計畫來設計。
5. [建構並清理變更](./05-build-and-clean.md)：各種建構劇本、`/tdd`、`/unslop`、`/no-comments`。
6. [驗證並出貨](./06-verify-and-ship.md)：在真實 app 上證明行為、用形式驗證檢查測試很少碰到的情況、用 `/benchmark-checklist` 檢驗數字，然後開一個聚焦的 PR 並推到合併。
7. [讓工作在你睡覺時進行](./07-overnight.md)：先建立信任再跑迴圈、整夜合約、可稽核的決策紀錄，以及能擴展到多個 agent 的 Projects 和自動化。
8. [用原則名稱來引導](./08-principles.md)：24 個能在任務中途扭轉 agent 方向的名稱。
9. [打造你自己的版本](./09-make-it-yours.md)：你自己的模式、用 `/correct` 處理重複犯的錯、如何測試技能的修改。
10. [食譜與陷阱](./10-recipes-and-pitfalls.md)：可以直接複製的提示詞，以及可以避開的錯誤。

第一次請照順序讀。之後每一頁都可以單獨查閱。

卡住了，或不知道該用哪個技能時，輸入 [`/poteto-help`](../../skills/poteto-help/SKILL.md) 加上你的問題：

```text
/poteto-help 我該用哪個技能來審查這個分支？
```

它會回答你、給你一段可以送出的提示詞，並附上答案出處（技能或指南頁面）的連結。它**不會**直接開始做事，因為跑一次 pstack 會花掉真實的 token（也就是錢），所以等你準備好再自己送出。只有你親自輸入它才會執行。

## 如果你只記得一件事

用你自己的話，給 agent 一個**目標**和一個**檢查方法**：

```text
/poteto-mode 執行到一半發生重試時，匯出會寫入重複的資料列。先重現，再修好並驗證。
```

你不需要指定劇本，也不需要列出技能。「先重現」加上一個可以檢查的結果，就是 `/poteto-mode` 需要的全部線索。它會對應到「修 bug」劇本，把步驟複製到待辦清單，並在每一步呼叫對的技能。

下一頁：[設定 pstack](./01-setup.md)。
